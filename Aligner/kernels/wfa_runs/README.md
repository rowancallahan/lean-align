# Codec `wfa_runs` — direct run-length traceback with scalar checker (`wfak`, fastest proven)

**Symbol.** `wfaAlignK` (kernel `wfak`).  Returns `Array (Step × Nat)` runs and the score.
**Claims.** `wfaAlignK_score`, `wfaAlignK_sound` (for `expandCigar` of the runs), `wfaAlignK_isSome`; and
`wfaAlignK_score_eq_wfaAlign` / `wfaAlignK_score_fun_eq` (`AlignmentWfaRunsVsWfa.lean`): the score function
EQUALS `wfaAlign`'s score function for every scoring and every input.
**How.** Small-error shortcut first (`wfa_small_errors`); otherwise the offsets wavefront of `wfa_offsets`, a
traceback that emits whole diagonal runs (`AlignmentTraceRuns.lean`, generated by `generate_run_trace.py`),
a scalar run checker proven sound (`checkRuns_sound`), and the level certificate (`certifiedRuns_spec`).  A
rejected candidate falls back to the proven `wfaAlign`; the traceback generator is outside the trusted base.
**Files.** `AlignmentCigarCheck.lean`, `AlignmentTraceRuns.lean`, `AlignmentWfaRuns.lean`, `Certificate.lean`.
**Check.** `lake env lean alignment/codecs/wfa_runs/Certificate.lean`
