# Codec `wfa_offsets` — offsets-only wavefront with certified traceback (`wfac`, `wfaca`)

**Symbols.** `wfaAlignC` (list inputs, kernel `wfac`), `wfaAlignCA` (array inputs, kernel `wfaca`).
**Claims.** `_score`, `_sound`, `_isSome` (same three as `wfa`); `wfaAlignCA_eq` relates the array kernel to
the list one.
**How (proof chain, bottom to top).**
1. `AlignmentWfaOff.lean` — the model level projects to an offsets-only level: `projL_nextLevel`
   (under the model invariant every push/demotion/extension is a function of offsets).
2. `AlignmentWfaOffLoop.lean` — `wfaRunO_spec`: if the offsets run reaches the corner at level L, the optimal
   score s satisfies `2 s + L = matchScore (m + n)`.  This is the runtime certificate.
3. `AlignmentWfaOffR.lean` — banded `Array Nat` fronts denote the offsets level (`rdenL_nextLevelR`).
4. `AlignmentWfaView.lean`, `AlignmentWfaDirect.lean` (generated by `generate_wfa_direct.py`),
   `AlignmentWfaPoint.lean` — fused / direct / pointwise array construction, each proven equal to 3
   (`nextLevelV_eq`, `nextLevelD_eq`, `nextLevelP_eq`); the executed one is the pointwise version.
5. `AlignmentWfaCertified.lean` — the executed loop equals the offsets loop (`wfaRunR_eq`); a traceback walk is
   accepted only if it is a valid walk whose recomputed score satisfies the certificate
   (`offsets_certify_score`, `walkCheck_sound`); otherwise the proven `wfaAlign` runs.
6. `AlignmentWfaArray.lean` — array-input execution refines the list kernel.
`AlignmentWfaLcp.lean` (4-character LCP chunks) is proven but not enabled.
**Check.** `lake env lean alignment/codecs/wfa_offsets/Certificate.lean`
